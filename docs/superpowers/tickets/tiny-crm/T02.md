## Acceptance criteria

- `sql/schema.sql` creates database `ShopCRM` if not exists.
- Creates `Users`, `Customers`, `Interactions` tables with all columns per spec (R1, R4, R5).
- `Customers.Status` has CHECK constraint `IN ('Lead','Contact','Customer')`.
- `Interactions.Type` has CHECK constraint `IN ('Call','Email','Meeting','Note')`.
- `Interactions.CustomerId` FK has `ON DELETE CASCADE`.
- Seeds 1 user (`admin` / BCrypt hash of `Admin@123`, role `Admin`).
- Seeds ~10 customers (mix of Lead/Contact/Customer statuses).
- Seeds ~3-5 interactions across customers.
- Script executed successfully on guest `.\SQLEXPRESS` via WinRM.
