> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare the Shop MVC project at `C:\src\Shop` for the Tiny CRM app, wire it to git, and update web.config for CRM-specific settings — so the site returns 200 at `http://localhost/Shop` after cleaning out shop demo content.

**Architecture:** The guest VM (`win-iis-dev`, `192.168.122.226`) already has an MVC 5.2.9 / .NET 4.7 project at `C:\src\Shop` with a `build-csc.ps1` build script that compiles via csc → copies to `C:\inetpub\wwwroot\Shop` → IIS serves at `/Shop`. We will: clean out the shop-specific Controllers/Models/Views, update `web.config` (session timeout 20, connectionStrings, customErrors On, authentication None), create a bare git repo on the host, push the cleaned source, and verify the site still builds and serves.

**Tech Stack:** .NET Framework 4.7, ASP.NET MVC 5.2.9, Razor, csc compiler, IIS, git bare repo, sshpass SSH bridge to guest.
